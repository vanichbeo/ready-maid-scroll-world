# Ready Maid Homepage V1.9 — PPL Layout Correction

## Root issue
V1.8 inserted the correct approved assets but kept the old dense prototype grid. This reduced the new high-resolution photos to tiny 78–95 px crops, placed the three service cards inside only one third of the desktop width, and gave the reception, DUKE, Licence C and logo assets insufficient visual hierarchy.

## Corrections
- Kept the approved origami hero as one complete, uncropped master image.
- Made Services a full-width section with three equal, large visual cards.
- Placed Matching Process and Meet DUKE beneath Services at an appropriate 2:1 visual balance.
- Increased image height, text size and whitespace throughout.
- Made agency proof a full-width section with intentional image treatment per asset.
- Licence C and master logo use `object-fit: contain`; people and office photos use controlled focal crops.
- Moved learning content and enquiry CTA into a balanced two-column row.
- Removed the mobile horizontal-scroll hero behaviour.
- Added responsive tablet and mobile stacking without changing the locked brand direction.
